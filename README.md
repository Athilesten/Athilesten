## Featured projects

### [Fraud Risk Intelligence Platform](https://github.com/Athilesten/fraud-risk-intelligence-platform)

Built a portfolio application that scores transactions with machine learning and rule-based checks. FastAPI serves the scores, PostgreSQL records decisions for audit, and Kafka and PySpark stream results into Delta Lake. Docker Compose runs the demo locally, with Prometheus and Grafana for monitoring.

### [Agentic SQL Data Analyst](https://github.com/Athilesten/Agentic-SQL-Analyst-project)

Contributed to the LangChain agent, SQL validation, prompt design, evaluation, and demos for a C-DAC team project. The application uses Gemini to translate plain-English questions into SQL, validates queries before read-only execution in PostgreSQL, and can retry failed queries through a correction loop.

### [Journal-Entry Audit Analytics](https://github.com/Athilesten/journal-entry-audit-analytics)

Analyzed 7,500 synthetic journal entries using PostgreSQL audit rules, Benford’s Law, and Isolation Forest. The pipeline ranks exceptions for review and exports the results for Tableau.

### [Real-Time Object Detection](https://github.com/Athilesten/yolo-opencv-object-detector)

Built a Python application that runs a pretrained YOLO model on webcam feeds and video files. OpenCV overlays bounding boxes, confidence scores, object counts, and FPS. I tested how lighting, input size, and confidence thresholds affected detection and speed.
